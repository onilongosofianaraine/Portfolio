# Sofia Naraine J. Onilongo

A sleek, modern developer portfolio for **Sofia Naraine J. Onilongo**, inspired by the minimalist design of [prathm.me](https://prathm.me/).

## ✨ Features & Design (Inspired by prathm.me)

- **Interactive Canvas Dot Field**: An interactive dot-matrix particle canvas at the top that responds dynamically to mouse pointer movement.
- **Minimalist Pixel & Satoshi Typography**: Pixel art logo (`SOFIA`), Satoshi font hierarchy, and subtle framing lines (`screen-line-bottom`).
- **Interactive Cursor Tooltip Follower**: Smooth cursor-following pill (`hi 👋`) across the screen.
- **Profile Header with Photo Switch**: Featuring Sofia's photo (`profile.jpg`) with a toggle switch between full color and monochrome portrait.
- **Animated Role Flipper**: Cycles smoothly between `Computer Engineering Student`, `4th Year BSCOE @ ICCT Colleges`, and `Problem Solver & Tech Enthusiast`.
- **Complete Information**:
  - **About**: Sofia's exact quote and personal story.
  - **Education**: **ICCT COLLEGES** (4th Year BSCOE) & **Vicente Madrigal Integrated School**.
  - **Job Experience**: Proudly entry-level (*"Job Experience: Wala pa hahahaha!"*) emphasizing high coachability, fast learning, and zero bad habits.
  - **Skills & Toolkit**: Microsoft PowerPoint, Microsoft Excel, Google Docs, Computer Systems Servicing, Logic Circuits, C++, Python, HTML/CSS, JavaScript.
  - **Connect**: 1-click email copy for `onilongosofianaraine@gmail.com` and GitHub link for `https://github.com/onilongosofianaraine`.
- **Command Palette (`Ctrl+K` / `⌘K`)**: Quick search dialog to instantly jump to sections, copy email, or open GitHub.
- **Sound & Theme Toggles**: Clean Web Audio synthesizer clicks, sound mute switch, and instant Dark/Light theme switching.
